## Cómo leer este portfolio

- **Activos**: proyectos en producción o desarrollo activo. Suelen tener compromisos con terceros.
- **Personales / experimentales**: side projects míos para explorar tecnologías o resolver problemas propios.
- **Académicos**: trabajos de pregrado e intercambio. Algunos quedaron archivados al cerrar el curso.

Cada case study incluye: **qué problema resuelve**, **arquitectura / stack**, **mi rol**, **estado actual** y **lecciones aprendidas**.
